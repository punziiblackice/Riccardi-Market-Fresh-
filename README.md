# Riccardi Market Fresh website

A polished one-page showcase website using the real photos supplied for Riccardi Market Fresh.

## Files to edit

- `index.html` — page words, links and layout
- `styles.css` — colours, spacing and responsive styling
- `script.js` — mobile menu and photo lightbox
- `assets/` — the two supplied Riccardi Market Fresh images

## Preview it on your computer

The simplest option is to double-click `index.html`. It will open in your web browser.

For the smoothest preview, open this folder in Visual Studio Code and install the **Live Server** extension. Then right-click `index.html` and choose **Open with Live Server**.

## Publish free with GitHub Pages

1. Create a GitHub account at [github.com](https://github.com) if you do not already have one.
2. Click **New repository**, name it `riccardi-market-fresh`, select **Public**, and create it.
3. On the repository page, choose **Add file → Upload files**.
4. Drag everything *inside* this `riccardi-market-fresh` folder into GitHub: `index.html`, `styles.css`, `script.js`, `README.md`, and the whole `assets` folder. Keep the folder structure exactly the same.
5. Click **Commit changes**.
6. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`. Click **Save**.
7. Wait a minute or two. GitHub will show your live website address near the top of the Pages screen.

## Important checks before publishing

- Ask the business owner to approve the wording, supplied photos, and artwork.
- The address and phone link are included from public business listings. Opening hours are purposely not shown: confirm them directly with the store before adding them.
- When you receive additional official Riccardi photos, put them in `assets/` and add them to the gallery in `index.html`.
